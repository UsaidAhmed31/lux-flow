# Lux Flow — Phase 1 (Connect) prototype

A mindful social platform prototype: Ten Systems home, Flow, Chat, People, Communities, Archive, Create, Journal, Calendar, Settings (with Dark / Light theme) and Trusted path.

## View it

- **`index.html`** — the whole prototype in one self-contained file (all images, fonts fallback and runtime embedded). Open it in any browser. On a laptop or desktop, use the **Web view / Mobile view** switch at the top. On a phone it opens full screen.
- If GitHub Pages is enabled for this repo, the same file is served at the Pages URL.

## Folders

| Folder | What it is |
| --- | --- |
| `portable/` | Multi-page export: `index.html` (prototype), `foundations.html` (design system), `brand.html` (brand exploration + website mock). Works offline. |
| `source/` | Design-canvas source files (`*.dc.html`) and image assets. |

## Notes

- This is a design prototype. Verification, moderation, notifications and all data are simulated in the browser; nothing is a real backend or production security.
- Prototype data is kept in your browser's local storage — use "Reset demo data" in Prototype controls to start over.
- Photography is under the Pexels License; replace identifiable people with owned or model-released images before production.
